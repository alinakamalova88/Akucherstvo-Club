# Akusherstvo Club

Многостраничный статический сайт на Astro 5 с блогом на Content Collections.

## Запуск

В этой папке выполните:

```sh
npm install
npm run dev
```

Сборка: `npm run build`. Папка `dist` содержит готовый сайт для статического хостинга.
Локальный просмотр сборки: `npm run preview`.

Адрес сайта в `astro.config.mjs`: `https://brilliant-lily-57de5c.netlify.app`. При подключении собственного домена обновите его и Sitemap в `public/robots.txt`.

## Структура и редактирование

- `src/pages/` — страницы, включая каталог, шесть услуг, контакты и схему проезда.
- `src/data/services.js` — услуги, цены, описания, ссылки на источники.
- `src/content/blog/` — две статьи Markdown.
- `src/styles/global.css` — общая адаптивная палитра без жёлтого: бежевый, пудровый, зелёный, персиковый, нежно-голубой.
- `public/images/logo.png` — присланный пользователем логотип, оригинал не изменён.
- `public/images/service-0.jpg` — `service-5.jpg` — шесть фотографий из исходного каталога.
- `public/images/meeting.png` — сгенерированная иллюстрация для главной и страницы «О нас».

## Среда и зависимости

Astro 7 из latest-шаблона не смог загрузить нативный компилятор из-за Windows Application Control. Для локальной сборки использован совместимый Astro 5 (соответствует требованию 5+). Windows-защита не изменялась.

`npm audit` для Astro 5 сообщает 3 группы уязвимостей: Astro, sharp и вложенный esbuild. Серверный рендеринг, загрузка/оптимизация пользовательских изображений и динамические HTML-атрибуты не используются; результат сборки статический. Сервер разработки привязан только к 127.0.0.1. Перед дальнейшим развитием/серверной публикацией обновить Astro в среде, где поддерживается актуальный компилятор. Не публиковать сервер разработки.
